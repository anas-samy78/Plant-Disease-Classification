# 🌱 Plant Disease Classifier - Web Application

تطبيق ويب تفاعلي لتصنيف أمراض النباتات باستخدام Streamlit

## الميزات

✨ **واجهة جميلة وسهلة الاستخدام**
- 🎨 تصميم عصري ملون
- 📱 متجاوب (Responsive)
- 🚀 سريع وسهل التنقل

🖼️ **خيارات متعددة لرفع الصور**
- 📤 رفع ملف محلي (JPG, PNG)
- 🔗 رابط صورة من الإنترنت
- 📸 استخدام الكاميرا (قريباً)

📊 **عرض النتائج الشامل**
- 🎯 الفئة المتنبأ بها
- 📈 درجة الثقة (Confidence)
- 📊 احتمالات جميع الفئات
- 🔍 معلومات تفصيلية عن المرض

## التشغيل

```bash
# تثبيت المكتبات
pip install -r ../requirements.txt

# تشغيل التطبيق
streamlit run app.py
```

سيفتح في: `http://localhost:8501`

## الملفات

- `app.py`: الكود الرئيسي للتطبيق
- `model_utils.py`: دوال مساعدة للنموذج

## المتطلبات

- Python 3.8+
- PyTorch
- Streamlit
- Pillow
- Pandas
- Matplotlib
